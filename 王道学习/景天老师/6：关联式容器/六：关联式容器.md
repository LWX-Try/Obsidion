## 6.1：set
---

    左<右

AVL树：平衡，防止单链表样式的树。

set：
set容器是关联式容器，存储单列数据，一个一个的数据。
1. 底层是红黑树。
2. 存储的数据是有序的，能比较大小，默认升序排序。
3. 存储的元素不能重复。
4. 主要的应用场景是，去重，排序。

map： 
m存储的是双列数据 一对一对的数据 属性名=属性值 key-value，<font color="#ff0000">存储的数据是pair对象</font>。
存储的数据key不能重复，value无所谓。

### 6.1.1：set的构造函数
set容器在头文件\<set>里面

// 迭代器方式遍历

set的底层是一个红黑树，vector的底层是一个数组。
**set的特征：**
**（1）set中存放的元素是唯一的，不能重复；**
**（2）默认情况下，会按照元素进行升序排列；**

set中的函数有很多，常用的set中的函数：
count，find，begin，end，size，empty，insert，erase

### 6.1.3：set的插入操作
![[set的插入操作.png]]
insert的参数是key，就是要插入的数据。

返回值是一个pair类型（）。
pair定义在头文件< utility >中，类似于结构体，可以存储两种不同类型的变量。
![[pair类型介绍.png]]
```C++
pair<int, string> p(1, "apple");

cout << p.first << endl;    // 1
cout << p.second << endl;   // apple

p.first = 10;               // 修改
p.second = "banana";
```

#### 插入单个元素
insert函数的返回类型是pair类型，包含两个对象成员，第一个是对应set的迭代器，第二个是bool值
- 如果插入成功，则返回“**插入元素对应迭代器**和**true**” ；
- 如果插入失败，则返回“阻止插入的元素（原本就有的这个元素）对应迭代器和false”.
```C++
set<int> nums = {1, 2, 3, 4};
// 完整类型
// pair<set<int>::iterator,bool> ret = number.insert(8);
// 借助auto简化
auto ret = nums.insert(8);
if(ret.second)
{
    cout << "该元素插入成功:"
        << *(ret.first) << endl;
}
else
{
    cout << "该元素插入失败，表明该元素已存在" << endl;
}
```

#### 插入多个元素
![[插入多个元素.png]]传入两个迭代器（首迭代器和尾后迭代器），尝试插入这两个迭代器范围中的元素；[,}区间
传入大括号列表，尝试插入列表中的元素。
```C++
void test()
{
    set<int> nums = {1,3,5,2};
    // 通过迭代器插入多个数据
    int arr[3] = {7, 4 ,6};
    nums.insert(arr, arr+3);
    for(auto & n : nums)
    {
        cout << n << " ";
    }
    cout << endl;
    cout << "size: " << nums.size() << endl;
    
    // 通过初始化列表插入
    nums.insert({100,200});
    for(auto & n : nums)
    {
        cout << n << " ";
    }
    cout << endl;
    cout << "size: " << nums.size() << endl;
}
```

- **set容器不支持下标访问**，因为没有operator[] 重载函数
- **不能通过set的迭代器直接修改key值**，set的底层实现是红黑树，结构稳定，不允许直接修改。
![[set的注意项.png]]

set中的迭代器和vector中的迭代器不一样。
set中的迭代器，一次只能移动一步。
set中的数值，不能通过\*it进行赋值。

set的遍历：
1. 增强for循环遍历
2. 通过迭代器方式遍历
相比一下vector少一种，普通的for循环不能用，因为底层不连续。

## 6.2：map
---
定义于头文件 `<map>`
它存储的是 **键值对**（key-value `pairs`），每个键（key）都与一个值（value）相关联。它通常用于快速查找、插入、删除操作，因为其底层通常使用 **红黑树**（或其他平衡树结构）实现，这使得它的平均查找时间复杂度为 O(log n)。

基本特征：
1. 有序容器。（默认升序）
2. 唯一键值。
3. 键和值关联，键唯一，值不唯一。

### 6.2.1：map的构造
map中存放的元素的类型是<font color="#ff0000">pair类型（键值对）</font>。
1. 通过初始化列表方式创建pair对象
2. 通过构造器创建pair对象
3. 通过make_pair方法创建pair对象
```C++
void test0(){
	map<int,string> number = 
	{
        {1,"hello"},// 通过初始化列表方式创建pair对象
        {2,"world"},
        {3,"wangdao"},
        
        pair<int,string>(4,"hubei"),
        pair<int,string>(5,"wangdao"), // 直接通过构造函数创建pair对象
        
        make_pair(9,"shenzhen"), // 通过make_pair方法创建pair对象
        make_pair(3,"beijing"),
        make_pair(6,"shanghai")
    }; 
    // 根据key值进行排序(默认升序)和去重
}
```
遍历map
```C++
// 完整类型
map<int,string>::iterator it = number.begin();

// 也可以使用auto简化
while(it != number.end()){
    cout << (*it).first << " " << it->second << endl;

```

#### \[ ]下标操作（重点）
<font color="#ff0000">map支持下标操作--->根据key获取对应value</font>

1. map下标操作返回的是map中元素（pair）的value
2. 下标访问运算符中的值代表key，而不是传统意义上的下标
3. 如果进行下标操作时下标值传入一个不存在的key，那么会将这个key和空的value**（默认的value值）**插入到map中
4. 下标访问可以进行写操作（只是对value进行写操作，不影响排序）
```C++
    map<int,string> container{
        {1,"zs"},
        {2,"ls"},
        {3,"zs"}
    };

    // 根据key 返回对应的value
    // read
    cout << container[1] << endl;
    cout << container[2] << endl;
    // write
    container[3] = "wangdao";
    cout << container[3] << endl;
```
