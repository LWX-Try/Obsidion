# 1：类的定义
---
类的定义中，分为两部分：
    1：属性：就是数据成员，
    2：行为：就是数据成员的行为。
C++中，用关键字class定义一个类，类的定义和声明如下：
```C++
// 类名采用大驼峰命名。
class MyClass                 //类的定义
{
    //……
    void myFunc(){}           //行为：成员函数，采用小驼峰命名。
    int m_a;                  //属性：数据成员。
};                            //一定要有分号。


//类也可以先声明，后完成定义。
class MyClass2;//类的声明

class MyClass2{//类的定义
    //……
};//分号不能省略
```
<font color="#ff0000">注意：类和结构体类似，但是又有很多不同。</font>
## 1.1：访问修饰符
定义一个computer类，类的属性有品牌和价格，类的行为有设置品牌，设置价格。
```C++
class Computer
{
    //属性：
    char    m_brand[20];
    float   m_price;
    
    //行为：
    void setBrand(const char * brand)
    {
        strcpy(m_brand, brand);
    }
    void setPrice(float price)
    {
        m_brand = price;
    }
}
//虽然我们现在已经定义好了一个类，但是现在还不能用。
//因为类中的每个成员都有自己的访问权限，访问权限默认为私有。
```
类中的成员都有自己的访问权限，默认为私有，可以使用以下三个限定符进行修饰：
1. public：公有访问权限，类内类外都可以访问。
2. protected：类内可访问，派生类中可以访问，类外不可访问。
3. private：类内可以访问，类外不可以访问。
类内默认访问权限是private。
## 1.2：struct和class的对比
1. C中的struct只能是一些变量的集合，可以封装数据但不能隐藏数据，而且成员不能是函数。
2. C++中的struct对C中的struct做了拓展，可以定义函数，基本等同于class，默认访问权限是public。
3. class默认访问权限是private。
<font color="#ff0000">注意：
C++中的struct和class最大的区别就是默认的权限，struct默认public，class默认private。
C++中的struct可以写属性（变量），可以写行为（函数），也构造函数，也有析构函数，也可以改变权限。
另外，struct的默认继承权限是public，class的默认继承权限是private。</font>
## 1.3：成员函数的定义
成员函数的定义有三种：
1：在类内定义。
2：在类外定义。
3：分文件定义，分为实现文件，头文件。

在类外定义，举例如下：
```C++
class Computer 
{
public:
	//成员函数 
	void setBrand(const char * brand)；      //设置品牌
	void setPrice(float price)；             //设置价格 
    void print();                            //打印信息
private:
	//数据成员
	char m_brand[20];
	float m_price;
};

// 定义成员函数的时候结合作用域限定符一起使用 
void Computer::setBrand(const char * brand)
{ 
    strcpy(m_brand, brand); 
}
void Computer::setPrice(float price)
{ 
    m_price = price;
}
```

分文件定义，举例如下：
```C++
class Computer 
{
public:
	//成员函数
	void setBrand(const char * brand)；//设置品牌
	void setPrice(float price)；//设置价格
    void print();//打印信息
private:
	//数据成员
	char m_brand[20];
	float m_price;
};

// 定义成员函数的时候结合作用域限定符一起使用 
void Computer::setBrand(const char * brand)
{ 
    strcpy(m_brand, brand); 
}
void Computer::setPrice(float price)
{ 
    m_price = price;
}
```
# 2：对象的创建
---
## 2.1：构造函数说明
虽然可以使用自定义的函数接口实现数据成员的初始化。
但是，实际上，C++提供了一种特殊的成员函数————<font color="#ff0000">构造函数</font>，来完成初始胡。
注意：
1. 构造函数没有返回值，void也不能写。
2. 函数名和类名相同，再加上函数参数列表。
3. 构造函数在创建对象时，自动调用。
## 2.2：构造函数使用
1：类中没有显式定义构造函数，默认无参构造函数。
2：类中显示定义了构造函数，编译器不会生成默认构造函数。
```C++
class Point 
{
public:
    //构造函数。
    Point()
    {
        cout << "Point()" << endl;
        m_x = 0;
        m_y = 0;
    }
    
	void print()
	{
		cout << "(" << m_x 
            << "," << m_y
			<< ")" << endl;
	}
private:
	int m_x;
	int m_y;
};

void test0()
{
	Point pt;
	pt.print();
}
//这次创建pt对象时就调用了自定义的构造函数，而非默认构造函数
```
3：构造函数可以重载，提高代码灵活性。
```C++
class Point
{
public:
    // 无参构造
    Point(){
        cout << "Point()" << endl;
    }
	// 两参构造
    Point(int x, int y){
        cout << "Point(x,y)" << endl;
        m_x = x;
        m_y = y;
    }
    // 一参构造
    Point(int x){
        cout << "Point(x)" << endl;
        m_x = x;
    }
    void print(){
        cout << "(x,y) = " << "("
            <<m_x << "," << m_y << ")"
            << endl;
    }
private:
    int m_x;
    int m_y;
};

void test(){
    Point p;// 调用无参构造
    p.print();
    
    Point p2(1,2);// 调用两参构造
    p2.print();
    
    Point p3(10);// 调用一参构造
    p3.print();
}
```



## 2.3：构造函数注意事项
1. 构造函数分为<font color="#ff0000">有参构造</font>和<font color="#ff0000">无参构造</font>。
2. 创建对象时，默认无参构造。
3. 构造函数可以重构。
4. C++11后，普通数据成员可以在声明时，进行初始化。（类似于默认值）
```C++
class Point {
public:
	//...
    int m_x = 0;//C++11
    int m_y = 0;
};
```
## 2.4：对象所占空间大小
可以用sizeof查看一个类或者对象的大小。
需要注意的是，成员函数不影响对象的大小。也就是说，类里面的函数，不计入大小计算。
另外，注意<font color="#ff0000">内存对齐。</font>
内存对齐的原因：
1. 平台原因(移植原因)：不是所有的硬件平台都能访问任意地址上的任意数据的；某些硬件平台只能在某些地址处取某些特定类型的数据，否则抛出硬件异常。
2. 性能原因：CPU 对内存的读取不是连续的，而是分成块读取的，块的大小只能是1、2、4、8、16 ... 字节。若不进行内存对齐，可能需要做两次内存访问，性能会大打折扣；而进行过内存对齐仅需要一次访问。
![[内存对齐.png]]
64位系统默认以8个字节的块大小进行读取。

如果没有内存对齐机制，CPU读取m_price时，需要两次总线周期来访问内存，第一次读取 m_price数据前四个字节的内容，第二次读取后四个字节的内容，还要经过计算，将它们合并成一个数据。

有了内存对齐机制后，以浪费4个字节的空间为代价，读取m_price时只需要一次访问，所以编译器会隐式地进行内存对齐。

对齐规则：
1. 按照类中，占空间最大的数据成员大小的倍数对其。
2. 一般按照，从小到大的顺序进行排序。
3. 如果数据成员中有<font color="#ff0000">数组类型</font>,会按照<font color="#ff0000">除数组以外的其他数据成员中最大的那一个</font>的倍数对齐。
4. 特殊情况：定义一个空类，依然可以创建对象，对象大小为1字节。
## 2.5：类中有指针成员
如果类中的成员有指针，那么就意味着创建类的对象的时候要进行指针成员初始化，需要在构造函数中申请内存。

那么销毁对象的时候，怎么释放内存呢？使用<font color="#ff0000">析构函数</font>。
如果不使用析构函数，就会产生内存泄漏。
# 3：对象的销毁
---
## 3.1：析构函数
析构函数主要就是回收对象的内存，因为对象中可能会申请空间，但是回收内存。

<font color="#ff0000">析构函数作为一个清理数据成员申请的堆空间的接口存在。</font>

析构函数的作用：清理资源。
- 释放动态内存：使用 `new` 分配的堆空间内存需要在析构函数中使用 `delete` 释放。
- 关闭文件句柄：如果在对象的生命周期中打开了文件，析构函数可以确保在对象销毁时关闭文件。
- 断开网络连接：在网络编程中，析构函数可以确保在对象销毁时关闭套接字连接。
- .......

形式：【特殊的成员函数】
- 没有返回值，即使是void也没有。
- 没有参数。
- 函数名与类名相同，在类名之前需要加上一个波浪号~

<font color="#ff0000">析构函数只有一个，不能重载。</font>
<font color="#ff0000">系统会默认提供一个析构函数。</font>
<font color="#ff0000">当对象销毁时，会自动调用析构函数。</font>

```C++
class Computer 
{

private:
	char * m_brand;
	double m_price;
public:

    //构造函数
    //构造函数的标准初始化是，使用初始化列表。
    //最好使用初始化列表，而不是在{ }内部初始化。
	Computer(const char * brand, double price)
	: m_brand(new char[strlen(brand) + 1]()) , m_price(price)
	{
    	cout << "constructor computer" << endl;
    	strcpy(m_brand,brand);
	}
    	
    	
	//析构函数
	~Computer()
	{	
        if(m_brand){
            delete [] m_brand;
        	m_brand = nullptr; //设为空指针，安全回收
        }
		cout << "~Computer()" << endl;
	}
	
};
```
## 3.2：析构函数的调用时机（重点）
1. 对于**全局对象**，**整个程序结束时**，自动调用全局对象的析构函数。
2. 对于**局部对象**，在**程序离开局部对象的作用域**时调用对象的析构函数。
3. 对于**静态对象**，在**整个程序结束时**调用析构函数。
4. 对于**堆对象**，<font color="#ff0000">在使用 delete 删除该对象时，调用析构函数。</font>
![[堆对象的销毁图解.png]]
实际上，如果类成员中没有指针，就是对象没有在堆上申请空间，默认的析构函数就够了。

注意：<font color="#ff0000">不要手动调用析构函数，否则对象销毁时会自动调用析构函数，对内存进行二次回收，这样会发生错误。</font>

另外：构造函数不是由对象调用的，而是编译器看到创建对象后，会自动生成一段代码，在这段代码中调用构造函数。<font color="#ff0000">所以构造函数不是有对象调用的。</font>
# 4：本类型对象的复制
---
## 4.1：拷贝构造函数
拷贝构造函数，也是一种构造函数。
拷贝构造函数：当使用一个已经存在的对象，去初始化一个新的对象的时候。
如果类中没有拷贝构造函数，编译器会自动创建一个拷贝构造函数。

对于自定义数据类型，我们希望有如下的效果：
```C++
Point pt1(1,2);
Point pt2 = pt1;               //希望，pt1可以直接给新建对象pt2赋值。
pt2.print();
```
虽然，在某些情况下直接这样写是可以的。
但是，<font color="#ff0000">当类里面有指针的时候，这种方式在销毁对象的时候发生错误。</font>
因为，默认拷贝是浅拷贝，指针的情况需要深拷贝。
所以我们需要使用拷贝构造函数。当创建的时候，可以直接进行深拷贝。

### 4.1.1：拷贝构造函数的定义
- <font color="#ff0000">拷贝构造函数也是一个构造函数。</font>
- 拷贝构造函数使用一个已经存在的同类对象，来初始化新对象。
拷贝构造函数形式：**类名(const 类名 &对象名)**
```C++
Computer pc("Acer",4500);
Computer pc2 = pc;//调用拷贝构造函数

//拷贝构造函数：下面代码是错误的。这里使用浅拷贝，应该使用深拷贝。
Computer(const Computer &rhs) : m_brand(rhs.m_brand) , m_price(rhs.m_price)
{
    cout << "Computer(const Computer &)" << endl;
}
```
![[拷贝构造函数.png]]
<font color="#ff0000">如果拷贝构造函数需要显式写出时（该类有指针成员申请堆空间），在自定义的拷贝构造函数中要换成深拷贝的方式，先申请空间，再复制内容。</font>
正确使用方法如下：
```C++
Computer(const Computer & rhs)
: m_brand(new char[strlen(rhs.m_brand) + 1]()), m_price(rhs.m_price)
{
	strcpy(m_brand, rhs.m_brand);
}
```
![[拷贝构造函数深拷贝.png]]
### 4.1.2：拷贝构造函数的调用时机（重点）
1：使用一个已经存在的对象初始化另外一个同类型新对象。
2：当函数参数时，这时候会发生拷贝。但是，为了不必要的拷贝，可以使用引用。
```C++
//当函数的实参和形参都是对象时,利用实参初始化形参,相当于值传递,会发生复制
// 为了避免这次多余的复制,可以将参数改为引用
/* void func1(Point & p) */           
void func1(Point p)             //最好使用引用
{
    p.print();
}

void test1()
{
    Point p(1,1);
    func1(p);
}
```
3：当函数的返回值是对象时，执行return语句时。为了不必要的拷贝，可以使用引用。
```C++
// 函数的返回值是对象时, 函数体中执行return语句时会发生复制
// 为了避免多余的复制,可以将函数的返回值改为引用,并且要确保引用绑定的对象的生命周期比函数更长
Point p(1,1);
/* Point & func2() */
Point func2()
{
    return p;
}

void test2()
{
    // 直接调用
	func2();
    // 使用对象接收
    Point p = func2();
    //编译器优化 可能看不到拷贝构造函数的调用 需要加上去优化参数进行编译
}
```
### 4.1.3：拷贝构造函数的形式解答
1：能不能去掉拷贝构造函数的&符号？
不能，从形式上讲，编译器不允许这样写，直接报错。
另外，逻辑上也不可以，因为形参和实参都是对象，会再次调用拷贝构造函数，形成递归调用，直到栈溢出，程序崩溃。
pt实参 拷贝给 rhs形参，会发生迭代。
![[能否去掉引用.png]]
2：拷贝构造函数能否去掉const？
不能，我只希望进行拷贝操作，不希望更改源对象。
如果不加const，可能会修改源对象。
### 4.1.4：左值和右值
左值 : 表示的是**一个占据内存并可以取地址的对象**。简单来说，左值是表达式**可以放在赋值运算符 `=` 左侧**的内容，是可以被**引用**的、持久存在的内存位置。
- 左值有**确定的内存地址**。
- 左值是可以被赋值的，即可以放在 `=` 左边。
- 左值通常表示一个变量或对象，可以通过引用来获取它的内存地址。
```C++
int x = 5;        // x是一个变量 是左值, 占据内存，有具体的地址
x = 10;           // x 可以被赋值，因此 x 是左值
int & ref = x;    // 非const引用只能绑定左值 
```
右值 : **没有明确存储位置的临时对象**，通常用于表达式的结果。右值是**不能取地址**的，通常表示临时的、短暂存在的值。
- 右值是**临时的值**，没有明确的内存地址，不能取地址。
- 右值通常是**字面常量**或**表达式计算的结果**。
- 右值只能放在赋值运算符的右边，不能作为左值（因为没有存储位置）。
```C++
int y = 5 + 3;         // 5 + 3 是右值，表达式的结果是一个临时值
int z = 10;            // 10 是一个字面常量，也是右值
// int & ref2 = 10; error 非const引用不能能绑定右值 
const int & ref = 10;  // const引用既可以绑定左值, 也可以绑定右值
```
```C++
// 左值和右值
void test2()
{
    // 左值
    // 有名字的变量
    int a = 1;
    &a;
    // 有名字的对象
    Point pt1{1,2};
    &pt1;
    &"hello";
    
    cout << "-----" << endl;
    // 右值
    // 匿名的对象
    &Point{3,4};
    int num1 = 1;
    int num2 = 2;
    &(num1 + num2);
    &100;
}
```
## 4.2：赋值运算符函数
### 4.2.1：赋值运算函数的的形式
赋值运算函数的是对于两个已经创建好的对象，想把A对象，赋值给B对象。
```C++
Point pt1(1, 2), pt2(3, 4);
pt1 = pt2;//赋值操作
```
和拷贝构造函数一样，希望可以直接进行拷贝，但是在某些情况下，这种方式会有问题。
比如类里面有指针的时候，类里面有申请空间的时候，会发生问题。

注意赋值运算符函数，不是一个重载函数。

形式：**类名& operator=(const 类名 &对象名)**
实际上，就是赋值符号的重载。

```C++
Point & operator=(const Point & rhs)
{
	m_ix = rhs.m_ix;
	m_iy = rhs.m_iy;
	
	return *this;
}
```
赋值号“=” ，是有返回值的。所以要返回本身。
这里的this指针，是一个指向对象的指针。
### 4.2.2：this指针
- this指针的本质，是一个常量指针。`Type* const pointer`。
- this指针指向本对象。
- 它储存了调用它的对象的地址，不可被修改。这样成员函数才知道自己修改的成员变量是哪个对象的。
- this是一个隐藏的指针，可以在类的成员函数中使用，它可以用来指向调用对象。当一个对象的成员函数被调用时，编译器会隐式地传递该对象的地址作为 this 指针。

this指针的生命周期：
<font color="#ff0000">this 指针的生命周期开始于成员函数的执行开始。</font>
<font color="#ff0000">this 指针的生命周期结束于成员函数的执行结束。</font>
要注意，this指针的生命周期与它所指向的对象的生命周期虽然并不完全相同，但是是相关的。
this指针本身只在成员函数执行期间存在，但它指向的对象可能在成员函数执行前就已经存在，并且在成员函数执行后继续存在。

1. 对象调用函数时，是如何找到自己本对象的数据成员的？         —— 通过this指针
2. this指针代表的是什么？                                                         —— 指向本对象
3. this指针在参数列表中的什么位置？
                         —— 参数列表的第一位（默认自动加入，不要手动写出）
4. this指针的形式是什么？                                 —— 类名 * const this （常量指针）

### 4.2.3：赋值运算符函数的定义
以computer类为例，默认赋值运算符函数为：
```C++
Computer & operator=(const Computer & rhs)
{
    this->m_brand = rhs.m_brand;
    this->m_price = rhs.m_price;

    return *this;
}
```
同样的，这里的拷贝是浅拷贝。会造成问题：
![[赋值运算符函数_浅拷贝.png]]
但是，这里不能直接进行深拷贝，会造成内存泄漏。
![[赋值运算符函数_深拷贝.png]]
所以，必须先回收原内存，再进行申请内存，进行拷贝。
**总结步骤—— 四步走（重点）：**
1. 考虑自赋值问题。                                         防止：自己给自己赋值。
2. 回收左操作数的数据成员原本申请的堆空间。
3. 深拷贝（以及其他的数据成员的赋值）。
4. 返回\*this（本对象）。
```C++
Computer & operator=(const Computer & rhs)
{
    // 1.自赋值情况判断
    if(this != &rhs)
    {
        delete [] m_brand; //回收当前对象中指针成员原来申请的堆空间
        
        m_brand = new char[ strlen(rhs.m_brand)+1 ](); // 深拷贝
        
        strcpy(m_brand,rhs.m_brand);
        m_price = rhs.m_price; // 其他数据成员的简单赋值
    }
    return *this; // 返回当前对象
}
```

1. 赋值运算符函数的返回必须是一个引用吗？
   必须使用引用，**否则会造成一次多余的拷贝，增加不必要的开销。**
2. 赋值操作符函数的返回类型可以是void吗？
   可以，但是无法连续赋值。不要这样子做。
3. 赋值操作符函数的参数一定要是引用吗？

4. 赋值操作符函数的参数必须是一个const引用吗？

## 5.4：静态数据成员
C++ 允许使用 static （静态存储）修饰数据成员，这样的成员在**编译时**就被创建并初始化的（与之相比，对象是在运行时被创建的），且其实例只有一个.
- 静态数据成员和之前介绍的静态变量一样，当程序执行时，该成员已经存在，一直到程序结束，任何该类对象都可对其进行访问;
- **静态数据成员存储在全局/静态区，并不占据对象的存储空间**。
- **静态数据成员被整个类的所有对象共享。**
```C++
class Student
{
public:
    Student(int id, const char* name)
    : m_id(id)
    , m_name(new char[strlen(name)+ 1]{})
    {
        strcpy(m_name, name);
    }
    
    ~Student()
    {
        if(m_name)
        {
            delete [] m_name;
            m_name = nullptr;
        }
    }
    
    void print()
    {
        cout << m_id << "," << m_name << endl;
    }

    // 静态成员作为班级ID
    static int ms_classID;// 静态的成员必须在类的外部进行初始化
private:
    int m_id;
    char *m_name;
};
// 类外部 静态成员的初始化
// 需要指明是在哪个类中定义的静态成员 类名::
int Student::ms_classID = 2;
```

静态成员规则：
1. private的静态数据成员无法在类之外直接访问（显然）
2. **对于静态数据成员的初始化，必须放在类外**（一般紧接着类的定义，这是规则1的特殊情况）
3. 静态数据成员初始化时不能在数据类型前面加static，在数据成员名前面要加上类名+作用域限定符
4. 如果有多条静态数据成员，那么它们的初始化顺序需要与声明顺序一致（规范）
5. 静态成员在访问时可以通过对象访问，**也可以直接通过类名::成员名的形式**（更常用）

## 6.1：静态成员函数
静态成员函数就是在某个成员函数前面加上static，静态成员函数有以下特征：
1：静态成员函数不依赖某个对象。
2：可以通过对象调用，但是更多的时候，通过类名加上作用域限定符进行调用。
3：静态成员函数没有this指针，因为他是属于类，而不是某个具体的对象。
4：<font color="#ff0000">静态成员函数无法直接访问非静态的成员（因为没有this指针）</font>，只能访问静态数据成员或者静态成员函数。
构造函数，析构函数，拷贝构造函数，赋值运算符函数比较特殊，可以在静态函数中调用。

注：但是非静态的成员函数可以访问静态成员。

```C++
class Computer 
{
public:
    //构造函数
	Computer(const char * brand, double price)
	: m_brand(new char[strlen(brand) + 1]())
	, m_price(price)
	{
        strcpy(m_brand, brand);
		ms_totalPrice += m_price;
	}
	
	//析构函数
    ~Computer()
    {
        if(m_brand){
            delete [] m_brand;
            m_brand = nullptr;
        }
    }

   	//...
    //静态成员函数
	static void printTotalPrice()
	{
		cout << "totalPrice:" << ms_totalPrice << endl;
        cout << m_price << endl;//error
	}
	
private:
	char * m_brand;
	double m_price;
	static double ms_totalPrice;
};
double Computer::ms_totalPrice = 0;
```
静态成员函数虽然不能直接访问对象中的非静态成员。但是可以间接的访问。
最常用的方法是通过<font color="#ff0000">对象参数访问</font>，把对象作为参数传进静态成员函数。
```C++

{

    int age;
public:
    Student(int a) : age(a) {}

    // 静态成员函数，通过参数接收对象
```

## 6.2：const成员函数
在成员函数的参数列表之后，函数执行体之前加上const关键字，这个函数就是const成员函数。
**形式:**`void func() const { }`
```C++
class Computer
{
public:
    //...
    void print() const
    {
        cout << "brand:" << m_brand << endl;
        cout << "price:" << m_price << endl;
    }
    //...
    void print()
    {
        cout << "brand:" << m_brand << endl;
        cout << "price:" << m_price << endl;
    }
};
```
**特点：**
1. const成员函数中，不能直接修改对象的非静态的普通数据成员；
2. 当编译器发现该函数是const成员函数时，会自动将this指针设置为**双重const限定的指针**`const Type* const pointer`，所以<font color="#ff0000">可以进行函数重载</font>，<font color="#ff0000">同名的非const版本的成员函数和const版本的成员函数。</font>

如果类中有两个不同版本的成员函数，const和非const同时存在：
1：普通对象，使用普通版本的成员函数。
2：const对象，使用const版本的成员函数。

如果类中只有const版本的成员函数
普通对象/const对象，都调用const版本的成员函数。

如果类中，只有非const（普通）版本的成员函数。
普通对象，调用非const版本的成员函数。
const对象，无法调用。

## 7.1：const对象
类对象也可以声明为 const 对象，一般来说，<font color="#ff0000">能作用于 const 对象的成员函数除了构造函数和析构函数，就只有 const 成员函数了。</font>
因为 const 对象只能被创建、销毁和只读访问，写操作是不允许的。

**const对象与const成员函数的规则：**
1. 当类中有const成员函数和非const成员函数重载时，const对象会调用const成员函数，非const对象会调用非const成员函数；

# 10：C++字符串
---
字符串对象的大小，在64位系统下常见的是32个字节（libstdc++（gcc编译器） / MSVC），或者24字节（libc++（clang编译器））。

这32个字节包含：
1. 一个指针（8字节）：指向堆上的字符缓冲区（如果字符串很长）。
   如果字符串比较短，在SSO缓冲区，则指向自己的SSO缓冲区。
   如果字符串比较长，在堆上，则指向堆上的字符缓冲区。
2. 一个 size 字段（8 字节）：当前字符数。是一个无符号整形（unsigned long）类型的字段。
3. 一个联合体（16字节）：既可以是 capacity 字段，也可以是一个 16 字节的**本地缓冲区（SSO）**。
**SSO（Small String Optimization，短字符串优化）**：当字符串长度小于某个阈值（libstdc++ 中是 15）时，字符直接存在对象内部的 16 字节缓冲区里，**不分配堆内存**。这就是为什么 `std::string` 对象要占 32 字节——它自带了一个小仓库。

从C++11开始，字符串末尾必须有一个 ‘\0’ ，是强制保证的，主要原因是为兼容C风格字符串。
 保证内容
- `s.c_str()` 返回一个以 `'\0'` 结尾的 C 风格字符串。
- `s[s.size()]` 返回 `'\0'`（读取合法，修改是未定义行为）。
- `s.data()` 返回的缓冲区在 `s.size()` 位置也是 `'\0'`。

如果是24个字节的实现，是使用了一个union，让长字符串和短字符串共享一块内存。
```C++
union {
    struct // 长字符串视图（24 字节）
    {  
        char*     data_;    // 8 字节：指向堆内存
        size_t    size_;    // 8 字节：当前长度
        size_t    cap_;     // 8 字节：容量（最低位为 1 标记“长模式”）
    } long_;
    
    struct // 短字符串视图（24 字节）
    {  
        unsigned char size_;  // 1 字节：长度 << 1（最低位为 0 标记“短模式”）
        char data_[23];       // 23 字节：内联字符缓冲区
    } short_;
};
```
- **长模式**：指针 + size + capacity，共 24 字节。
- **短模式**：1 字节长度 + 23 字节缓冲区，也恰好 24 字节。
两种模式**共用同一块 24 字节**，所以 `sizeof(std::string)` 永远是 24。

2. 动态插入和删除。
3. 动态访问。

vector底层结构是三个指针：
1：M_start
2：M_finish
3：M_end_of_storage
（不同版本的名字可能不一样，但是作用都是一样的。）

## 11.1：vector的构造
vector常见的几种构造形式：
1. 无参构造，仅指明vector存放元素的种类，没有存放元素。
   `vector <int> numbers;`
2. 传入一个参数，指明vector存放元素的种类和数量，参数是存放元 素的数量，每个元素的值为该类型对应的默认值。
   `vector<long> numbers2(10);           //存放10个0`
3. 传入两个参数，第一个参数为vetor存放元素的数量，第二个参数为每个元素的值（相同）。
   `vector<long> numbers2(10，20); //存放10个20`
4. 通过列表初始化vector，直接指明存放的所有元素的值。
   `vector<int> number3{1,2,3,4,5,6,7};`
5. 迭代器方式初始化vector，传入两个迭代器作为参数，第一个为首迭代器，第二个为尾后迭代器。
```C++
vector<int> number3{1,2,3,4,5,6,7};
vector<int> number4(number3.begin(),number3.end() - 3);
//推测一下，number4中存了哪些元素
```
## 11.2：vector的常用操作
vector常用的对象操作，使用对象可以调用的常用函数：
```C++
iterator begin();                      //返回首位迭代器
iterator end();                        //返回尾后迭代器
bool empty() const;                    //判空
size_type size() const;                //返回容器中存放的元素个数
size_type capacity() const;            //返回容器容量（最多可以存放元素的个数）
void push_back(const T& value);        //在最后一个元素的后面再存放元素
void pop_back();                       //删除最后一个元素
void clear();                          //清空所有元素，但不释放空间
void shrink_to_fit();                 
//释放多余的空间（可以存放元素但没有存放元素的空间 capacity-size）
void reserve(size_type new_cap);        //申请空间，不存放元素(不初始化元素)
```
常用的vector遍历有三种方式：
```C++
vector<int> nums{1,2,3,4,5};
//1：使用增强的for循环
for(int &num : nums)
{
    cout << num << " ";
}
cout << endl;

//2：使用下标方式
for(size_t i=0;i<nums.size();i++)
{
    cout << num[i] << " " ;
    cout << num.at(i) << " ";
}
cout << endl;

//3：使用迭代器访问。
auto it = nums.begin();
while(it != nums.end())
{
    cout << *it << " ";
    it++;
}
cout << endl;
```
**vector不仅可以存放内置类型变量，也能存放自定义类型对象，和其他容器。**
比如存放string类型，存放自定义的student类型，存放vector类型（容器嵌套）。

容器库里面有很多容器，vector只是其中的一种容器。
可以使用vector容器，创建一个vector容器对象，这个对象本身的大小是24个字节，里面是有三个指针构成的，往容器里面放东西，这个对象的大小并不会发生改变。
- **容器对象本身的大小（`sizeof`）**                            —— 固定不变。
- **容器总共占用的内存（包括堆上的动态内存）**          —— 会增加。
**往动态容器（`vector`、`string`、`list`、`map` 等）里加数据，不会改变容器对象本身的大小（`sizeof` 恒定），但会增加它在堆上动态分配的内存总量。**

## 11.3：vector的动态扩容
当vector容器存放满后，仍然追加存放元素，vector会进行自动扩容。

- <font color="#ff0000">GCC的vector是2倍的容量扩容机制：当vector存满后再添加新的元素，容量就会变成2倍，把新的元素存入其中。</font>
- <font color="#ff0000">VS上是1.5倍的扩容。</font>

其工作步骤如下：
（1）开辟空间
（2）Allocator分配（后面STL阶段学习）
（3）复制，再添加新元素
（4）回收原空间

## 11.4：vector的底层实现（重要）
利用sizeof查看vector对象的大小时，发现无论存放的元素类型、数量如何，其大小始终为24个字节（64位环境）因为vector对象是由三个指针组成。
![[vector的底层实现.png]]
**_start：指向当前数组中第一个元素存放的位置。**
**_finish：指向当前数组中最后一个元素存放的下一个位置。**
**_end_of_storage：指向当前数组能够存放元素的最后一个空间的下一个位置。**

可以推导出
size() : _finish - _start
capacity(): _end_of_storage - start


迭代器是不是指针？
迭代器是广义上的指针。迭代器不是一个指针，但是可以像指针一样使用。
迭代器是一种数据类型。

对于自定义类型数据，C++中的运算符，直接不支持的。
如果想支持自定义类型的数据进行运算符操作，需要使用运算符重载。
